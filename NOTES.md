- Stage 9 (pub15): Coach mode. Engine is now makeGame(h, a, ctx, userSide, {rec, coach}) -> {T, ev, step() one minute, done(), finish() writes stats once, timeout(i), lateLeft(), slice}; playPoss = run it straight through (identical results to before when coach is off; calibration rechecked 1996 99.5 ppg, 2026 115.5). Coach-only mechanics (both teams): energy x.en (drain .018/min scaled by stamina, game pace, pressure, star usage; +.045/min on bench; quarter/half/OT rest), effective ovr = ovr - 32*(1-en)^1.4, lineup strength vs the rotation's average shifts efficiency (K_MARGIN*DRIFT*(dl_o-dl_d)/(2gp)), momentum +2.5% at an 8-0 run, 6 timeouts each (AI calls one at a 9-0 run, keeps 2), AI fouls when down 3-9 in the last minute. Tactics t.c: pace -1/0/1, off bal|in|three|star (+star index), def norm|press|pack|foul, auto subs or t.lock five. Balance measured with mc.mjs/mc2.mjs (thousands of games): default coaching = plain sim; threes -1.4 to +0.5 by own shooting; inside +1.1 vs weak rim protection, -0.5 vs strong; pack +1 vs poor shooters, -3 vs good; press about 0 on average, up to +1.5 vs careless teams; slow costs a favourite ~0.8; starters all game about -0.9 (2024), 0 (1996); timeouts +0.7; Hack-a-Shaq all game -1.6 with ~9 foul-outs. UI: play sheet "Coach your next game" (regular + playoffs) -> sheet {k:"coach"}, UI.coach (not saved): Tactics / Lineup / Plays / Box, Start/Pause, speed, timeout, auto-pauses at quarter breaks, 2 minutes left in a close game, an 8-0 opponent run, a 5th foul under manual subs. "Sim to the end" (and the close button) finishes with the coach on subs. endCoach puts the game in COACH and runs playDays(1)/playPlayoffs("day"); simGame takes it from there (injury risk rises past 38 minutes). Reloading mid-game discards it. Test: t17.mjs.

- Stage 16 (pub22): Team strategy and player tendencies. Data: build_data.py adds two tendencies per player row (season rows r[23] drive = 25 + 6*FTA/36, r[24] usage = 25 + 2.96*((FGA+.44FTA+TOV)/36 - 5), both blended with the prior like the other ratings; class rows c[19], c[20]) and each team's real pace (teams[i][9] = possessions per game vs the league, 1000 = average). App: p.r[15] drive, p.r[16] usage (ext() makes them up for generated players; migrate() takes real players' values from their first available real row/class, otherwise ext; mkDist 17). prof(): w2 now excludes free-throw points (so 2PA match real), wfd = foul-drawing weight (FTA/36), uf = usage factor. Engine: every team has a plan in every game (planFor: user's t.st {pace, off, star, def, rot} with "auto" = coach; AI = autoPlan vs the opponent using scout ranks, only for a clear edge: inside if their rim ranks bottom quarter and our ins/drive top third; threes if our three top quarter and their rim top third; press if their ball security bottom quarter and our steals top half; pack if their threes bottom quarter). Tactic effects (same as coach mode) now apply in simulated games too; coach-only parts (energy, lineup strength, momentum, timeouts, fouling on purpose) stay coach-only. Pace: t.pv = clamp((realPace-1000)/60, -1, 1); game possessions x (1 + .04*(pace_h + pace_a)) in all games (coach mode was .06). Foul rate per team t.ff = (team wfd / league)^.6 clamped .8-1.25, used in the efficiency solver and possessions; fouled shooter picked by wfd; FT% in solver weighted by wfd; nsf .092 (was .1). Late close games (last 3 min, within 6): shots go to high-usage players (weight x uf^2). Rotation: rotOf = user choice, auto = tight in the playoffs; tight starters x1.09 bench x.8, deep x.915/x1.2 (max 42 min); net() charges -.35 ovr per extra minute, +.15 per minute rested; injury chance x clamp(1 + (min - normal)/8, .7, 1.6). UI: Team strategy sheet (roster page button; chips with what the coach would pick next game and why), roster Style line (pace word + top/bottom quarter ranks) and Plan summary, player page "How he plays" (styleOf labels from league percentiles: Go-to/Volume scorer, Volume shooter, Slasher/Post scorer, Shooter/Three-point specialist/Stretch big, Mid-range shooter, Playmaker/Point forward/Passing big, Glass cleaner, Rim protector, Perimeter stopper, Ball hawk, Defense first) + Shot volume / Getting to the line bars, list tags now style words, box score "Game plans" line (G.log pl), coach mode starts from the plan and notes the opponent's plan. Measured: 2016 Harden 29.0 ppg 19.4 FGA 10.2 FTA (real 29.0/19.7/10.2; before 24.8 FGA 5.9 FTA); league stat shifts small (TOV +.3, STL +.4, PF +.8, FTA +.5); AI plan worth ~+.5/game vs plain (mc.mjs 1500 games); 5-season 2024 run stable.
